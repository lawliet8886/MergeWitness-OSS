# MergeWitness 0.2.1 - local release candidate

This independent version is prepared locally. No maintained remote, public release, npm publication or site deployment has been performed. See the [validation record](evidence/VALIDATION_0.2.1.md) for the actual acceptance receipts and remaining gates.

- Added known lru-cache stale-disposal and fastq pause/resume incidents, extending the source corpus from ten to twelve cases. Exact licensed published modules, declared observations and retained behaviors are recorded in [provenance](../fixtures/cases/PROVENANCE.md).
- Preserved published bytes inside the generated Git snapshots/candidate as well as in the source vendor directory, including under `core.autocrlf=true`. The runner checks module/dependency hashes before and after evaluation/verification and records actual probe-run counts. Earlier Windows byte-execution claims are corrected in the [review record](evidence/REVIEW_0.2.1.md).
- Updated CLI/MCP/package identity to 0.2.1. The version-2 core and existing commands remain the interface; no runtime npm dependency or provider API was added.
- Prepared scoped QuietClash comparison, external-installation protocol, contribution/publication materials and a truthful application draft. These establish preparation, not demand, adoption, public distribution or program selection.
- Updated local site package links and the copied instruction to run from the documented installation prefix. Source/command checks pass; internal-browser attachment failed, so rendered desktop/mobile, clipboard interaction, console and video acceptance remain pending.

Initial distribution, when specifically authorized, is a GitHub release tarball with SHA256SUMS and QUICKSTART. The package stays `private:true`; a public npm release is not part of this milestone. The original IBM competition checkout/history/license and the existing 0.2.0 artifact/receipts are preserved.
