# MergeWitness 0.3.1 — Windows correction candidate

When Git and Node spelled a Windows drive differently, a valid repair worktree could be rejected as belonging to another analysis. Version 0.3.1 uses native canonical paths for common-directory identity while preserving the exact ownership check, containment and all frozen requirements. The independent nested-clone negative control remains required.

CLI, stdio MCP metadata and the optional installed-example companion now identify 0.3.1. The local-first API, supported Node runner, synthetic demo and offline evidence reader are otherwise unchanged.
